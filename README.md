# 💼 Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website created to showcase my skills, projects, education, and contact information.

The website provides a clean and user-friendly interface and is designed to work smoothly across different devices, including mobile phones, tablets, laptops, and desktop screens.

## ✨ Features

* 🏠 Attractive Home / Hero Section
* 👨‍💻 About Me Section
* 🛠️ Skills Showcase
* 📂 Projects Section
* 🎓 Education and Qualifications
* 📱 Fully Responsive Design
* ✨ Smooth Animations and Interactive Elements
* 📧 Contact Section

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📱 Responsive Design

The portfolio is optimized for:

* Mobile Devices
* Tablets
* Laptops
* Desktop Screens

## 🎯 Purpose

This portfolio website was created to showcase my web development skills and projects while building a professional online presence.
